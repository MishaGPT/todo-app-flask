
# Список справ з ШІ-модулем

Веб-застосунок на Flask, який автоматично визначає категорію завдання за допомогою власної моделі машинного навчання, навченої в Google Colab.

## Можливості
- додавання, виконання та видалення завдань (база даних Google Firestore)
- автоматична класифікація завдання: Навчання, Робота, Дім, Здоров'я, Покупки
- сторінка /stats з таблицею й діаграмою за категоріями
- JSON-ендпоінт /api/classify?text=...

## Архітектура
- Flask (Python) – серверна частина
- Firestore – хмарна база даних
- scikit-learn (TF-IDF + логістична регресія) – модель ШІ, файл model.pkl
- Google Cloud Run – хмарне розгортання
- GitHub Actions – автоматичне розгортання (CI/CD)

## Командна робота
- гілка main – стабільна версія
- нові функції розробляються в гілках feature/* і потрапляють у main через Pull Request

## Запуск локально
    pip install -r requirements.txt
    export GOOGLE_CLOUD_PROJECT=lab6zubel
    python app.py
